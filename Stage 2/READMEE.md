# FlexSight – Temperature Monitoring & Alert System

## Stage 2: Project Charter Development

### Overview

FlexSight is an IoT-based temperature monitoring and alert system designed to improve operational safety in environments such as server rooms, warehouses, factories, and data centers.

The system continuously collects temperature readings from embedded monitoring devices, transmits data through MQTT/API communication, processes incoming data on a central server, and displays real-time information through a monitoring dashboard.

When abnormal temperature levels are detected, the system automatically generates alerts to support early intervention and reduce potential equipment damage or operational risks.
