# Flex Sight — Temperature Monitoring & Alert System

## Overview

Flex Sight is a lightweight embedded temperature monitoring and alert system designed to improve safety in environments such as warehouses, server rooms, factories, and data centers.

The system monitors temperature readings using embedded sensors and sends data in real time through MQTT/API communication to a central server. When the temperature reaches a critical level (approximately 50°C), the system automatically triggers an alert on the dashboard.

Core workflow:

MQTT/API → Server → Dashboard Alert

The project focuses on providing a simple, scalable, and efficient monitoring solution that supports early detection of overheating risks and faster response to safety incidents.
